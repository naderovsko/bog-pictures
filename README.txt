BOG PICTURES website — simplified Android upload package

IMPORTANT: Upload all 8 files directly to the root of your GitHub repository.
There is NO assets folder to create.

Files:
- index.html
- styles.css
- script.js
- projects.js
- site-config.js
- bog-pictures-logo.png
- hero-cover.png
- README.txt

After uploading, enable GitHub Pages:
Repository Settings → Pages → Deploy from a branch → main → /(root) → Save.

Video links are added later in projects.js. Contact details are added in site-config.js.
